# lyrivaMusic v1.3.3

## 阅读与设置

- 在「歌词 → 阅读排版」通过加减按钮或直接输入百分比调整歌词字号、译文大小和行距，支持分别重置。
- 双语模式支持将译文放在原文上方或下方；逐字、逐行和静态歌词使用相同设置。
- 调整排版时保留歌词内容和阅读位置，无需重新获取歌词。
- 设置按阅读排版、同步校准、歌词效果、窗口与卡片、备用来源分组，顶部搜索框居中。
- 工具栏按钮、悬停提示和通知统一为透明磨砂样式；通知随文字收缩居中，长文本自动换行。
- 移除歌词下方的中英学习词卡及相关开关。

## 加载与恢复

- 歌词加载失败时显示网络、超时、限流或服务异常提示，并提供原位「重试」。
- 普通视图中没有找到歌词时，可以点击「重新获取」请求当前歌曲。
- 主动重试绕过旧缓存，避免切歌或关闭页面后，旧请求覆盖当前歌词。

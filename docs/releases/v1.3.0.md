## 自动更新

- GitHub 发布新正式版本后，Spotify 会自动打开更新页并下载更新。
- 更新页显示版本、更新说明和进度；下载与校验完成后，点击「重新加载」启用新版，也可以留到下次启动。
- 关闭更新页不会中断下载，同一个版本不会反复弹出。
- 设置 → 高级 → 版本与更新可手动检查或查看更新状态。
- 下载失败继续使用原版本；新版本启动失败时，下次启动回退到上一可用版本。

## 首次升级

从 v1.2.0 或更早版本升级，需要**手动安装一次**下方的 `lyrivamusic.js`，覆盖 Spicetify 的 `Extensions/lyrivamusic.js` 后执行 `spicetify apply`。之后普通版本更新会在 Spotify 内完成。

`lyrivamusic-runtime.js` 和 `manifest.json` 是自动更新组件，请勿把 runtime 作为另一份扩展安装。`SHA256SUMS.txt` 提供文件校验值。

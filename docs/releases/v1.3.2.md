# lyrivaMusic v1.3.2

## 更新页

- 重新设计版本与更新面板，统一深色半透明风格，突出版本状态、下载进度和主要操作。
- 更新说明支持标题、列表、链接和代码块；长内容独立滚动，底部操作始终可见。
- Release 仅提供一个安装附件 `lyrivamusic.js`，自动更新所需组件由更新通道分发。

## 歌词体验

- 小窗口自动使用紧凑布局，保留原有字体与常用工具栏。
- 修复逐字歌词的译文顺序，译文显示在原文下方。
- 调整长音高亮、远处歌词的模糊效果，并适配减少动态效果的系统偏好。
- 优化播放进度条的拖动、键盘操作与画中画交互。

已安装 v1.3.0 或更新版本的用户可在「设置 → 高级 → 版本与更新」检查更新，下载完成后重新加载 Spotify 生效。首次安装或手动升级只需下载 `lyrivamusic.js`，覆盖 Spicetify 扩展目录中的同名文件后运行 `spicetify apply`。
